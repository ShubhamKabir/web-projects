# Web Projects

A collection of independent web experiences built to explore different product, design, interaction, and technical directions.

Each project is a standalone Next.js application with its own visual identity, structure, and purpose.

## Projects

### VERA — AI SaaS
AI product landing experience focused on intelligent workflow automation, combining editorial design with a technical product interface.

**Directory:** `vera/`

### EMBER — Restaurant
Contemporary restaurant website built around hospitality, atmosphere, editorial typography, and immersive food-focused presentation.

**Directory:** `ember/`

### NOVA — Startup
Modern startup/product website exploring bold typography, interactive product previews, and a high-energy visual system.

**Directory:** `nova/`

### FORM — Agency
Creative agency website focused on typography, art direction, asymmetrical layouts, and editorial presentation.

**Directory:** `form/`

### ATLAS — E-commerce
Premium lifestyle e-commerce experience with product discovery, categories, product detail pages, cart, checkout, journal, and brand storytelling.

**Directory:** `atlas/`

### PULSE — Web App
A functional project-management web application with authentication screens, dashboard, projects, tasks, calendar, team, activity, and settings interfaces.

**Directory:** `pulse/`

### PROJECT HADAL — Deep-Sea Research Archive
An immersive deep-sea research experience combining cinematic descent, scientific telemetry, specimen discovery, sonar, and an archival interface.

**Directory:** `project-hadal/`

## Technology

The projects primarily use:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

Individual projects may use additional libraries depending on their requirements.
